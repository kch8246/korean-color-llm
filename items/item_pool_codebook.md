## 2. 가설(사전 등록용 초안, 실험 전 확정·고정)

- H1: 음성모음계(큰말)가 양성모음계(작은말)보다 "어둡고 탁한/크고 묵직한"으로 선택된다.
- H2: 된소리형이 예사소리형보다 "강하고 선명한"으로 선택된다.
- H3: 강조 접두사형 > 기본형 > 약화 접미사형 순으로 강도 순위가 나온다.
- H4: 어종 고정 표현(적신호, 레드카드 등)은 어종을 바꾸면 자연스러움이 하락한다.
- H5: 선택지에 상위어(갈색 등)가 있으면 하위어(밤색 등) 정답률이 낮아진다(S3a hyper vs nohyper).
- H6: 대상 이름과 글자가 겹치는 함정 선택지(감색, 밤색)가 있으면 정답률이 낮아진다(S3b trap vs control).
- H7: 어원 문항은 모델 간 편차가 크고, 응답의 부가 어원 주장에 환각이 나타난다.
- H8: 관용 표현을 문자 의미로 오독하거나, 문자 용법을 관용으로 과잉 해석하는 비율이 모델·언어에 따라 다르다.
- H9: 모델 평정과 모어 화자 평정의 상관은 모델 간 차이가 있다.
- H10: 어종×상황 상호작용(공문서=한자어, 광고=외래어, 일상=고유어계)이 나타난다.
- H11: 영어 지시문과 한국어 지시문 사이에 정답률 차이가 있다.
- H12: 상위어 편향 문서가 많을수록(biased_3 > biased_1) 상위어 선택률이 오르고, 검색을 쓰는 모델에서 더 크다.
- H13: 거짓 전제(justify_wrong)에서 모델이 반박하지 않고 합리화하는 비율, 설명-먼저 조건에서 답 변경률을 측정한다.

## 4. 실행·채점 규약 (권장)

1. **순서 무작위화**: `shuffle` 항목은 호출마다 시드를 바꿔 선택지 순서를 섞고, 사용한 순서를 로그에 저장하세요. 정답은 선택지 문구로 채점합니다(번호가 아니라).
2. **출력 형식**: 응답을 JSON(`{"answer": ..., "reason": ...}`)으로 받는 조건을 기본으로 하되, S0는 1차 결과와 비교하기 위해 원문 그대로, 자유 서술로 한 번 더 수집하세요.
3. **S8**: 같은 모델의 "문서 없음" 기준선은 `base_item_id` 문항(S3a hyper)을 사용합니다. 검색 도구 on/off 조건은 S3a·S3b에서 별도로 돌리세요.
4. **S9**: `justify_gold`/`justify_wrong`은 모델이 전제를 반박하는지, 설명의 언어학적 주장이 정확한지 코딩합니다. 설명 중 음상징·어원 주장은 추출해 사전·문헌과 대조하세요(근거 환각률).
5. **S7 채점**: 영어 선택지는 한국어 선택지와 같은 순서의 번역입니다. 순서를 섞더라도 대응 인덱스로 한국어 쌍과 비교하세요.
6. **개방형(S0 Q2/Q3/Q5, S6 개방형)**: 정답이 없으므로 질적 코딩(범주는 1차 논문 부록 4의 사전을 확장, 2인 코더 + 블라인드 + κ).

## 5. 사용 전 반드시 확인할 것 (정직한 한계)

- **모든 gold는 연구자 초안입니다.** 특히 `gold_confidence=medium` 문항(S1b, S1c, S3a의 상위어 포함 변이형, S3b nightsky, S4 '하얗게 불태우다')은 사전·모어 화자 대조 후 확정하세요. 평정·순위 문항은 설문 평균으로 정답을 만드는 구조라서 `gold`가 비어 있습니다.
- **S1a의 `가맣다/거멓다`, `발갛다/벌겋다` 등은 저빈도어**가 섞여 있어, 모델이 틀리더라도 음상징 이해 부족이 아니라 빈도 효과일 수 있습니다. 분석 시 빈도 통제(코퍼스 빈도 열 추가)를 권합니다.
- **S3 어원(c)** 문항은 제가 아는 범위(갈색=褐, 회색=灰, 미색=米, 감색=紺 등)에서 작성했으며, 표준국어대사전으로 한 번 더 대조가 필요합니다. 종속 질문 '곤색'은 문항 자체가 일본어 유래 표기를 묻는 구조라 논란 여지가 있는지 검토하세요.
- **S8 문서는 연구용 합성 텍스트**입니다. 실제 웹 검색(Perplexity·CLOVA 등)과는 조건이 다르므로, "합성 문서 주입 실험"과 "실제 검색 실험"을 논문에서 구분해 기술하세요. `biased` 문서는 사실과 모순되지 않게(밤 껍질은 실제로 갈색) 썼습니다. 오답을 주입하는 조건이 아니라 상위어 빈도 조건입니다.
- **S2는 14틀이라 변이형 간 비교에 쓸 수 있지만, 통계 검정력은 낮습니다.** 어휘 틀을 더 늘리거나 설문 응답자를 충분히 확보하세요.
- **S5·S6의 '검은색/흰색'**은 고유어 '검-/희-'에 한자 '색'이 붙은 혼성어라 순수 고유어가 아닙니다. 논문에서는 "고유어계"로 표기하세요.
- 모든 평정 문항(S2, S5, S6)은 같은 문항을 모어 화자 설문에도 제시해야 의미가 있습니다. 설문은 문항 풀을 그대로 쓰되 선택지 순서만 무작위화하면 됩니다.
